IT Education | تعليم IT - Python Basics for Android

Features in this revision:
- Embedded Python 3.10 runtime using Chaquopy; code execution is offline after installation.
- Python examples and challenge solutions for the included eight lessons.
- Output and runtime/syntax error display.
- Arabic branding: تعليم IT / IT Education.
- Local system fonts and no Internet permission required for the learning flow.
- LocalStorage is used to keep lesson progress on the device.

Build notes:
- Open this folder in Android Studio.
- Gradle needs internet on the first build to download Android/Chaquopy dependencies and the Python runtime.
- After the APK is built and installed, executing Python code does not need internet.
- This environment has not built or run the APK; please build and test on Android Studio before distribution.
